## 本地运行环境搭建（已完成）
- 无 `.venv`，全新搭建：`python -m venv .venv`（Python 3.13.14）。
- pip 必须绕坑：默认索引 `pypi.tuna.tsinghua.edu.cn` 对 pip UA 返回 403（curl/urllib 正常），且 build isolation 拉不到 hatchling。解决：`-i https://pypi.org/simple` 并 `env -u HTTP_PROXY -u HTTPS_PROXY`（沙箱代理 127.0.0.1:56465 会干扰）。
- `tradingagents`（git 源）装不上，已跳过——代码里是延迟导入 + 优雅降级（`_check_availability`），不影响启动。
- 5 个本地 editble 包需在装好 hatchling/setuptools 后单独 `-e` 安装。
- 前端：`npm i -g pnpm@9.15.9 --registry=https://registry.npmmirror.com`（corepack prepare 失败）；`pnpm install` 用 npmmirror。
- **构建坑**：`pnpm build` 会被仓库自带 UI 规范检查拦住（`SchedulerHistoryPanel.tsx`:228/293、`TokenUsage.tsx` 多处滚动区缺 scrollbar 类，共 10 处，既有问题）。绕过方式：`pnpm exec tsc -b && pnpm exec vite build`，再把 `frontend/dist/*` 复制到仓库根 `static/`（build.sh 同款约定）。
- 启动：`.venv/Scripts/python.exe server.py`，**端口 8888**（server.py 内写死，README 的 8000 已过时），UI 与 API 同端口。启动时股票列表部分目录抓取会因网络断连告警，不阻断。
